Подключить библиотеку Справочник API

Подключение

Клонируйте репозиторий рядом с приложением и добавьте зависимости в его Cargo.toml. Для сборки нужен Rust с поддержкой edition 2024.

Настройте маршрут

Создайте sift-gate.toml в рабочем каталоге приложения. Этот минимальный конфиг направляет алиас claude в AITUNNEL. Задайте AITUNNEL_API_KEY в окружении перед запуском.

Один алиас может иметь несколько записей [[models.claude]]. У каждой укажите провайдера, его API ID модели и допустимые протоколы. Пример с AITUNNEL и ProxyAPI · Список провайдеров

Запросы и стриминг

Anthropic и SSE

Для Anthropic вызывайте gate.messages(body) с полем max_tokens. Библиотека подставляет API ID модели и передаёт остальные поля провайдеру. При "stream": true результат приходит как ProviderResponse::Stream. Читайте события через futures_util::StreamExt::next и обрабатывайте ошибки каждого события. Переиспользуйте экземпляр SiftGate, чтобы сохранить кэш и телеметрию.

Маршрутизация и сбои

LowestCost
Сравнивает оценочную стоимость запроса. Маршруты без сопоставимой цены идут после маршрутов с ценой. Для смешанных RUB и USD задайте rub_per_usd.
LowestLatency
Сравнивает сглаженную задержку. Для SSE используется время до первого содержательного события, для JSON — время до полного ответа.
Balanced
Смешивает оценки цены и задержки. Доля задержки задаётся параметром latency_weight.

Переключение при сбое

При временном сбое роутер может попробовать следующий подходящий маршрут. После первого выданного SSE-события обрыв возвращается как ошибка потока. timeout_ms применяется к каждой попытке. Чтобы не повторять запрос после таймаута, задайте retry_timeouts = false.

Метод gate.telemetry(provider, model, protocol) возвращает замеры конкретного маршрута. Используйте API ID модели провайдера.

Расширения

Для OpenAI-совместимого API используйте kind = "compatible" с base_url и api_key_env. Для нестандартного транспорта или авторизации реализуйте ProviderAdapter и зарегистрируйте адаптер через SiftGate::with_extensions. Для собственной стратегии реализуйте ScoringPolicy.
